Glide is one binary that sits under whatever terminal you already use and keeps today's plan where you type.
Your priorities live in a Markdown note you own, in a folder you already sync.
The agent you run in the terminal gets the same verbs you do, so the status writes itself while the work happens.

```
▶ ship portal tests · focus 1/3 · 4 open · 2 logged
```

That line is `glide focus`. It goes in your tmux status bar or your prompt, and it changes as you and your agent work.

![glide in a terminal: focus set, the agent logs, done, the note, and what an agent sees at session start](/docs/demo.gif)

## How to glide

One day, start to finish.

1. **Morning.** `glide show` lists today's items from your note. Pick one: `glide focus set portal`. That is the line in your status bar now.
2. **While you work.** Run your agent as usual. It read your focus when the session started, and after each task it logs a line to Record on its own. When something comes up, `glide focus capture ask about the cache revert`, or just tell the agent to remember it.
3. **When it ships.** `glide focus done portal`. The box gets checked, the tag comes off, the strip counts it. Set the next one.
4. **Evening.** `glide today`. What you meant to do, what happened, and what came up, in order, with times. Nothing to write from scratch.

Six verbs, one note, and the status bar tells the truth all day.

## What it does

- **Focus.** The one thing you are on, tagged in your own note and printed where you type.
- **Record.** What actually happened, timestamped, written by the agent that did the work.
- **Capture.** Ideas and questions, one line into Notes without leaving the shell.
- **Agents.** Claude Code, Warp, or any MCP client gets the same six verbs, with standing instructions to read your focus at the start of a session and log at the end.

## What it never does

Glide reads and edits four sections of today's note: Focus, Tasks, Record, Notes.
Everything else in the file survives byte for byte.
No daemon, no account, no server, no lock file.
Nothing leaves your machine.

## Start here

1. [Install](/docs/how-to/install/) it with Homebrew or one line of curl.
2. Follow the [quick start](/docs/tutorials/quick-start/): point it at your notes, wire in your agent, put the line on screen.
3. Read [the daily note contract](/docs/reference/daily-note/) once, so you know exactly what it touches.
