Day to day

# ship
$ scripts/release.sh 0.2.0            # from clean, current main; refuses otherwise
$ gh run watch --repo matthewvilaysack/glide

# patch a shipped line
$ scripts/patch.sh <sha-on-main>        # cuts release/0.1 from v0.1.0 if missing, opens the PR
# merge the PR  →  v0.1.x tagged and published

# install what shipped
$ curl -fsSL https://raw.githubusercontent.com/matthewvilaysack/glide/main/install.sh | sh
$ brew install matthewvilaysack/glide/glide   # once the tap exists

Runbook: docs/releasing.md. Nothing is signed or notarized; a curl or brew install is not quarantined, so checksums are the guard.
